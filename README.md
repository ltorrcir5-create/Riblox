# Riblox 🎮

**Professional Modern UI Script for Roblox**

A feature-rich, professionally designed GUI for Roblox with smooth animations, comprehensive player features, and an intuitive interface.

## ✨ Features

- 🎨 **Professional Loading Screen** with animated progress
- 👤 **Player Controls**: Speed, Jump Power, Flight, Noclip, Infinite Jump
- 🎮 **Game Utilities**: Teleport, Auto Farm, Item Collection
- 👁️ **Visual Enhancements**: ESP, Full Bright, FPS Counter
- ⚙️ **Advanced Settings**: Server management, GUI controls
- 🔔 **Real-time Notifications**
- 🎯 **Smooth Animations** powered by TweenService
- ⌨️ **Keyboard Shortcuts** (Right Shift to toggle)
- 🛡️ **Anti-AFK System**

## 🚀 Quick Start

1. Open `RibloxUI.lua`
2. Copy the entire script
3. In Roblox, create a **LocalScript** in:
   - `StarterPlayer > StarterPlayerScripts`, or
   - `StarterGui`
4. Paste the script and run!

## 🎯 Controls

- **Right Shift**: Toggle GUI on/off
- **R Button** (top-left): Open/close GUI
- **Drag Title Bar**: Move the window
- **Flight Controls**: WASD + Space/Shift
